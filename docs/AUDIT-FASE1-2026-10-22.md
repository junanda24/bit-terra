  `('return this')()` mengembalikan `globalThis` asli (E5c). Akar: pembacaan

- **SCR-H2 — Polusi `Object.prototype` dari kode pemain.**

  setter `memberRef` (:173/:188) tanpa blocklist. Integritas halaman hilang,
  persisten antar-run.

## Addendum — Gelombang Perbaikan "Tahap A" (2026-10-22, atas perintah user "kerjakan semua phase")

Dikerjakan 3 agent paralel + verifikasi pusat Vex. Suite standar: **206/206** (22 berkas), tsc bersih, build hijau.

**Tertutup — semua 7 HIGH:**
- SCR-H1/H2/H3: interpreter kini hanya memanggil fungsi yang diciptakan sandbox sendiri (WeakSet `callables`); kunci `__proto__`/`constructor`/`prototype` diblokir (baca → undefined, tulis → FriendlyError); anggaran langkah total 25.000 (fib(26) mati ±0,8 dtk sebagai error ramah); bom string dibatasi 100 rb karakter; objek registry hanya-baca; bayangan registry kalah oleh scope pemain; panah berbadan ekspresi mengembalikan nilai; linter ditulis ulang jadi penganalisis scope leksikal (kesepakatan lint↔run pada 25/25 kasus korpus kecuali aritas/tip, di luar cakupan) dan memangkas cabang mati statis.
- SQL-H1: `SqlStatementGuard.executeGuardedSql` — snapshot sebelum run, efek tulis terlihat, DB selalu dipulihkan (termasuk error di tengah batch), penyelesaian diblokir untuk run terkontaminasi, narasi rollback via Pohon Induk. `QuestDefinition.sqlWritesAllowed` disiapkan untuk Q8.
- SQL-H2: alias ORDER BY/GROUP BY/HAVING, nama CTE (divalidasi mandiri), identifier kurung siku (dinormalkan ke backtick dengan tokenizer sadar string).
- CORE-H1: `completeQuest` mengembalikan boolean penyelesaian-pertama; +20 hanya dibayar sekali.
- UI-H1: sudah tertangani refactor layout sebelumnya (mode tab mobile + panggung terkunci aspek).

**Tertutup — MED/LOW dalam cakupan gelombang:** SQL-M1 (9 kelas error runtime dinarasikan akurat + bebas pajak fokus), SQL-M2 (baris sumber dibaca ulang pasca-run; tabel digerakkan `sqlSourceTable`), CORE-M2 (flush save di pagehide/visibilitychange), CORE-M3 (sanitize bersama; hydrate memvalidasi sendiri), CORE-M4 (diagnostik membuka DB `bit-terra` sungguhan tanpa membuat cangkang kosong), CORE-L1 (fokus NaN tidak lagi jadi 100), CORE-L9 (penjaga lag scheduler < 30 sumber), CORE-L6 (logError jalur muat quest).
